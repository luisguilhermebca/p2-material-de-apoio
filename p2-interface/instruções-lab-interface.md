# Como aproveitar o laboratório

Recomendo esta sequência:
    1. Execute cada demonstração e observe o resultado.
    2. Abra os arquivos Java correspondentes.
    3. Modifique os métodos e atributos.
    4. Tente provocar erros de compilação.
    5. Resolva os desafios sem consultar o gabarito.

Objetivo: fazer você entender interfaces não apenas lendo definições, mas prevendo o comportamento do código, identificando erros e experimentando diferentes implementações.
